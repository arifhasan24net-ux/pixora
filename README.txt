PIXORA — FREE IMAGE WEBSITE STARTER

WHAT'S INCLUDED
- index.html: homepage and gallery
- styles.css: responsive design
- script.js: image data, search, category filters, preview dialog
- about.html, license.html, privacy.html, contact.html: starter information pages
- netlify.toml: basic Netlify publishing settings

IMPORTANT
The homepage currently uses sample external photos from Unsplash to demonstrate the layout. These are not AI-generated by Pixora. Before public launch, replace them with AI-generated images you created and have rights to distribute. Verify all licensing and commercial-use terms for your image-generation service.

HOW TO DEPLOY ON NETLIFY (NO BUILD COMMAND NEEDED)
1. Download and extract pixora-website.zip.
2. Open https://app.netlify.com/ and sign in or create an account.
3. In the Netlify dashboard, find the option to manually deploy a site / drag and drop a folder (the wording may change).
4. Upload the extracted pixora-website folder, or drag the files/folder into the manual deploy area.
5. Wait for deployment, then open the generated .netlify.app URL.
6. Test search, categories, image preview, and download on your phone.

TO ADD YOUR OWN IMAGES
Open script.js in a text editor. Each image is one object in the images array. Update title, category, tags, description, and url. For a first test, upload your own image files into an "images" folder and set the url to "images/your-file.jpg". Then re-zip and redeploy the full folder.
